Personal server backup integration

This is a private integration maintained by the owner of the GitHub account MarcusY2k. It uses rclone to back up the owner's Linux server files and configuration to the owner's Google Drive. It is not a public service and does not accept registrations.

The Google OAuth desktop client named rclone Server Backups is used to authorise this integration. Google Drive access is used to upload backup archives, list and inspect backup metadata, verify uploads, and delete older backup archives under the owner's retention policy. The intended backup destinations are specific backup folders, but the access permission granted by Google may be broader than those folders; the Google consent screen specifies the permissions requested.

This website is informational only. It does not perform Google sign-in, receive OAuth tokens, or store backup archives. Never submit passwords, client secrets, authorisation codes, tokens, or backup files through this website or a public GitHub issue.
