My local Agent — Personal Server Backups

Purpose and operator

This is a personal integration operated by MarcusY2k for backing up the operator's own Linux server to the operator's Google Drive. It is not offered to the public.

Google data and permissions

After the account owner explicitly authorises access through Google, rclone uses OAuth credentials to access Drive. The backup workflow uploads server backup archives, lists archive names and metadata such as file sizes, verifies uploaded files, and deletes older backup archives according to the operator's retention policy. Backup archives can contain personal information and server configuration. The intended workflow uses designated backup folders, but Google permissions may permit broader Drive access; consult the consent screen for the actual scope.

Storage and sharing

Backup archives are stored in the operator's Google Drive, and local archives or working copies may exist on the server during the backup process. OAuth credentials are stored in the local rclone configuration and must be treated as secrets. Operational logs may contain archive names, sizes, timestamps and errors. The integration does not sell Google user data, use it for advertising, or intentionally publish backup contents. Google processes the data as the Drive provider.

Retention and control

The backup workflow applies the operator's configured retention policy. The account owner can delete archives in Drive and any retained local copies and can revoke the integration's access through Google Account security settings. Revoking access stops future authorised operations but does not itself delete existing archives or local credentials.
